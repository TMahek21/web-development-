# web-development-

 #project description
 This project involves of making a basic website for students , which provides with the facilities.

 # problem defination 
students often have to visit different websites or offices for attendance, results, fee payment, event registration, announcements, and certificates. This project aims to bring these services together in one portal to make them easy to access and the throught out process for everyone easier.Because student often struggle with constant issue of councellor submission , constant visits for approval of certificate , attendance and informing the faculty.  

# User - foe students where the aim is to provide everything to them on one platform 

#facilities provided or objective 
- Login to the portal
- View profile
- Check attendance 
- View timetable along with their attendance (also apply for leave and inform in case of attending events) 
- Check examination results and papers with request or complains
- View and search important announcements
- Register for events
- View and download/print certificates
- Access the fee portal
- Change account settings according to their needs
